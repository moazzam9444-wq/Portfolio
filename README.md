# Personal Portfolio

A modern and responsive personal portfolio website built to showcase my skills, projects, experience, and background as a Full-Stack Developer.

The portfolio is designed with a clean dark theme and a simple user-friendly layout. It highlights my technical skills, featured projects, qualifications, references, and contact information.

## Features

- Modern and responsive design
- Clean dark theme
- About Me section
- Skills and technologies
- Projects showcase
- Experience and qualifications
- References section
- Contact information
- Responsive navigation bar
- Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Responsive Design
- Git & GitHub

## Purpose

This project was created as part of my journey in learning Full-Stack Web Development and to showcase my progress, skills, and practical projects.
